# 文字花火サンプル

`ThankYou/ThankYou.prefab`は「ありがとう！」、`Multiline/Multiline.prefab`は「また会おう／この空の下で」の文字花火です。
Prefabをワールドへ配置し、青いボタンをInteractして再生してください。初期状態では−Z側の観覧エリアへ向いています。

`Settings.asset`には編集用の初期設定を保存しています。再生成する場合は文字花火エディターで開き、手持ちの日本語対応TMPフォントを指定してください。
生成済みPrefabの再生にはフォントは不要です。第三者のフォントや音源は含みません。

`SerializedUdonPrograms`はサンプルに付属するUdonプログラムです。SDKのコンパイル時には必要に応じて再生成されます。
サンプルを既存ワールドへ配置した後は、ワールドのSDKビルドとVRChat内での動作を確認してください。
